# Nhật ký Giáo viên – GVCN & Toán (FULL)

Web app tĩnh triển khai dễ dàng trên GitHub Pages.

## ✅ Tính năng
- Ghi chú theo **Chế độ**: Chủ nhiệm / Toán
- Lọc theo **Lớp**, **Thẻ** (tự động nhận #thẻ trong nội dung), **Ghim**, **Hôm nay**, **Có học sinh**
- Tìm kiếm toàn cục (tiêu đề, nội dung, thẻ, lớp, học sinh)
- **LaTeX/MathJax** (\(x^2\), \[\int_0^1 x^2 dx\])
- **Light/Dark Mode**
- **Export/Import JSON**
- **In ra PDF** (CSS @media print)
- **PWA**: `manifest.json`, `sw.js`

## Deploy nhanh (Pages từ branch main)

1. `git init && git add . && git commit -m "init"`
2. Thêm remote & push
3. Settings → Pages → Deploy from a branch → `main` / root
